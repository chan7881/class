■ 2. 상황별 프롬프트 예시
---------------------------------------------------------------------

  [A] 계획대로 다음 단계를 이어서 만들고 싶을 때

      docs/PROGRESS.md 에 적힌 다음 단계를 이어서 진행해줘.
      끝나면 PROGRESS.md 갱신하고 커밋·푸시까지 해줘.


  [B] 수업하다가 버그를 발견했을 때

      학생 화면에서 (증상을 구체적으로) 문제가 있어.
      예) "모바일에서 3번 슬라이드의 다음 버튼이 눌리지 않아"
      예) "빈칸 문항에 답을 넣었는데도 다음으로 안 넘어가"

      원인을 찾아서 고치고, 같은 문제가 다시 안 생기게
      테스트도 추가해줘. 고친 내용은 PROGRESS.md에 기록해줘.

      ※ 증상은 최대한 구체적으로: 어느 화면 / 어떤 조작 /
        무엇을 기대했는데 / 실제로 무슨 일이 일어났는지.
        가능하면 수업 코드와 화면 캡처도 같이 주세요.


  [C] 새 기능을 추가하고 싶을 때

      (기능 설명)을 추가하고 싶어.
      docs/PLAN.md 의 설계 원칙(특히 blocks/registry.ts 패턴)에
      맞게 구현해줘. 계획을 벗어나는 결정이 필요하면
      docs/DECISIONS.md 에 이유까지 기록해줘.


  [D] 새 문항 유형을 추가하고 싶을 때

      새 문항 유형 "(이름)"을 추가해줘.
      기존 문항들과 똑같이 src/blocks/questions/ 아래에 폴더를
      만들고 registry.ts 에 등록하는 방식으로 해줘.
      채점 로직은 lib/grade.ts 에 넣고 단위 테스트도 붙여줘.


  [E] 디자인·문구만 바꾸고 싶을 때

      (화면 이름)의 (요소)를 (어떻게) 바꿔줘.
      전체 디자인 원칙(단색·심플·모바일 우선)은 유지해줘.


  [F] 그냥 지금 상태만 확인하고 싶을 때

      CLAUDE.md 와 docs/PROGRESS.md 읽고, 지금까지 뭐가 됐고
      뭐가 남았는지 정리해서 알려줘. 코드는 아직 건드리지 마.

■ 5. 계획서(PLAN.md · 구현계획서.docx) 수정하기
---------------------------------------------------------------------

  [ 왜 두 벌인가 ]

    docs/PLAN.md          ← 진짜 원본. 다음 세션의 Claude가 읽는 파일.
    docs/구현계획서.docx   ← 위 파일을 Word로 변환한 사본.
                             사람이 읽고 인쇄·공유하는 용도.

    Claude는 .docx 를 바로 읽지 못합니다.
    그래서 PLAN.md 는 절대 지우면 안 됩니다.
    Word 파일만 남기면 다음 세션에서 계획을 참조할 수 없게 됩니다.


  [ 절대 규칙 ]

    수정은 항상 PLAN.md 에 먼저 → 그 다음 Word로 다시 변환.

    Word 파일을 직접 고치면 안 됩니다.
    직접 고치면 PLAN.md 와 내용이 어긋나고,
    다음에 변환할 때 그 수정이 통째로 사라집니다.


  [ 계획을 바꾸고 싶을 때 프롬프트 ]

  ┌───────────────────────────────────────────────────────────────┐
  │ docs/PLAN.md 에서 (바꾸고 싶은 내용)을 수정해줘.              │
  │ 수정한 뒤 docs/구현계획서.docx 도 다시 만들어줘.              │
  │ 계획이 바뀐 이유는 docs/DECISIONS.md 에 기록해줘.             │
  └───────────────────────────────────────────────────────────────┘

    예)
      docs/PLAN.md 에서 문항 유형에 "표 채우기"를 추가해줘.
      수정한 뒤 구현계획서.docx 도 다시 만들어줘.

      docs/PLAN.md 의 8단계에서 사진 업로드 기능을 빼줘.
      개인정보 문제로 안 쓰기로 했어. 이유도 DECISIONS.md에 남겨줘.
      그리고 Word 파일도 다시 만들어줘.


  [ Word 파일만 다시 만들고 싶을 때 ]

  ┌───────────────────────────────────────────────────────────────┐
  │ docs/PLAN.md 을 Word로 다시 변환해서                          │
  │ docs/구현계획서.docx 를 갱신해줘.                             │
  └───────────────────────────────────────────────────────────────┘

    ※ 변환에는 이 PC에 설치된 MS Word 와 Python 을 사용합니다.
      둘 다 이미 설치되어 있는 것을 확인했습니다.
      변환 중에는 구현계획서.docx 파일을 닫아두세요.
      (Word에서 열어둔 채로는 저장이 실패합니다)


  [ 계획과 실제 코드가 달라졌을 때 ]

    구현하다 보면 계획과 다르게 만들게 되는 부분이 반드시 생깁니다.
    그때는 계획서를 고쳐서 현실과 맞춰두세요. 그대로 방치하면
    다음 세션의 Claude가 낡은 계획을 사실로 믿고 작업합니다.

  ┌───────────────────────────────────────────────────────────────┐
  │ 지금 코드 상태와 docs/PLAN.md 내용이 어긋나는 부분이 있는지   │
  │ 확인하고, 실제 구현에 맞게 PLAN.md 를 갱신해줘.               │
  │ 왜 계획과 달라졌는지도 DECISIONS.md 에 적어줘.                │
  │ 마지막에 Word 파일도 다시 만들어줘.                           │
  └───────────────────────────────────────────────────────────────┘

■ 6. 백업 — 컴퓨터가 바뀌거나 폴더가 사라졌을 때
---------------------------------------------------------------------

  이 프로젝트는 GitHub에 백업되어 있습니다.
  (리포 주소는 docs/OPERATIONS.md 에 기록해 둡니다)

      npm install
      claude

  그 다음 위 「1. 만능 시작 프롬프트」를 붙여넣으면 됩니다.

  ※ 학생 답안과 수업 데이터는 GitHub이 아니라 Google Drive에
    있습니다. 코드와 데이터는 별개로 관리됩니다.

■ 7. 자주 겪는 문제
---------------------------------------------------------------------

  Q. Claude가 프로젝트를 전혀 모르는 것 같다
     → 폴더를 잘못 잡고 실행했을 가능성이 큽니다.
       0번 항목대로 프로젝트 폴더에서 다시 실행하세요.

  Q. 예전에 만든 수업이 안 열린다
     → 스키마가 바뀌었을 수 있습니다. 이렇게 말하세요:
       "예전에 만든 수업이 안 열려. lib/migrate.ts 에
        마이그레이션을 추가해서 열리게 해줘."

  Q. 실수로 코드를 망가뜨린 것 같다
     → "마지막 커밋 상태로 되돌려줘" 라고 하세요.
       커밋되어 있다면 안전하게 복구됩니다.

  Q. Word 계획서를 직접 고쳤는데 다음에 열어보니 사라졌다
     → Word 파일은 PLAN.md 에서 매번 새로 만들어지는 사본입니다.
       직접 고친 내용은 다시 변환할 때 덮어써집니다.
       5번 항목대로 항상 PLAN.md 를 먼저 고치세요.

  Q. Word 변환이 실패한다
     → 구현계획서.docx 를 Word에서 열어둔 상태면 저장이 막힙니다.
       파일을 닫고 다시 시켜보세요.

  Q. 교사용 편집 링크(editToken)를 잃어버렸다
     → 복구 불가능합니다. 해당 수업은 다시 만들어야 합니다.
       편집 링크는 만들자마자 반드시 북마크하거나
       메모장에 붙여넣어 두세요.
