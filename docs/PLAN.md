## 무엇을 왜 만드나

교사가 만든 학습 자료(PPT/학습지)와 학생 응답 수합(구글폼)이 **분리되어 있어**,
"읽고 → 바로 답하고 → 다음으로" 이어지는 탐구형 수업 흐름이 끊긴다.
Rubin Observatory의 Investigations처럼 자료와 문항이 한 흐름에 섞인 형태를 만들되,
교사가 코딩 없이 저작할 수 있게 하고 **과학 수업에 특화**한다.

### 확정된 결정 (사용자 승인 완료)

- 백엔드: GitHub Pages 정적 SPA + Google Apps Script 웹앱 + Google Drive/Sheets
- 배포 모델: **중앙 배포 1개** — 운영자 계정에 한 번만 배포, 모든 교사가 공유
- 스택: React + Vite + TypeScript
- 학생 식별: 수업 코드 + 학년·반·번호·이름 (**로그인 없음**)
- 그래프: 교사 데이터 → 차트 **AND** 학생 입력 → 실시간 그래프
- 채점: 자동 채점 + 정오답 즉시 공개 여부는 **수업 기본값 + 문항별 덮어쓰기**
- 교사 **미리보기 + 테스트 모드** 포함
- 영상: **URL 붙여넣기 + 구간 재생** (시청 강제·중간질문은 범위 밖)
- 이 사이트는 수업을 하면서 **계속 고쳐 나가는 물건**이다 — 인계 체계가 0단계였다

### 입력 방식에 대한 핵심 제약 (사용자 지시) ★

> **학생은 LaTeX 문법을 모른다고 가정한다.** 수식·화학식은 전부 **버튼**으로 입력할 수 있어야
> 하고, 화학식 첨자는 자동 변환이 아니라 명시적인 위/아래첨자 버튼으로 넣는다.

이 제약이 라이브러리 선택을 결정했다 → **MathLive**(시각적 수식 편집 + 커스터마이즈 가능한
가상 버튼 키보드, 출력은 LaTeX).

## 과학 특화 기능 설계

### 1. 수식 입력 — 버튼만으로 (`mathlive`)

- **교사 본문**: TipTap 커스텀 인라인 노드 `mathInline`. 저장은 LaTeX, 표시는 KaTeX.
- **학생 답안**(`kind:'math'`): MathLive + **커스텀 가상 키보드**. 교사가 문항별로 레이어를 고른다.
  `basic`(사칙·지수·첨자) · `letters`(영문 대소문자) · `fraction`(분수·루트·로그) ·
  `symbols`(부등호·근사·집합·기하·미적분·화살표 33종) · `greek` · `unit` · `chem`
- **채점**: `normalized`(기본, 공백·`\left\right`·중복 중괄호 제거 후 비교 + 복수 정답) /
  `symbolic`(옵션, `compute-engine`을 **동적 import** — 번들이 커서 쓰는 문항이 있을 때만)

### 2. 수치 답안 — 허용오차·유효숫자·단위 (`kind:'numeric'`)

- 단위 칸은 **드롭다운 + 자주 쓰는 단위 버튼**으로 제공해 오타를 막는다. 지수는 `×10^` 버튼.
- 채점 순서: ① 값 파싱(`3.0e8`·`3.0×10^8` 모두) → ② 단위 정규화 → ③ 허용오차 → ④ 유효숫자.
- 단위 정규화는 **소규모 레지스트리를 직접 구현**한다(SI 접두어 + 기본 7단위 + 자주 쓰는 유도단위).
  **범용 차원해석 엔진은 만들지 않는다 — 과잉 구현이다.**
- `unitMode:'convertible'`이면 1 km = 1000 m로 환산, `'required'`면 정확히 일치해야 한다.

### 3. 화학식 — 자동변환 없이 버튼으로 (`kind:'chem'`)

- 툴바: `X₂`·`X²` 토글 · `→` · `⇌` · `Δ` · `·` · `⁺` · `⁻` · `(s)(l)(g)(aq)` · `↑`·`↓`·`↔`
- 첨자는 **토글 버튼을 누른 뒤 타이핑**한다. H2O를 자동으로 H₂O로 바꾸지 **않는다.**
- 채점 정규화: 공백 제거, 유니코드 첨자 ↔ 일반 문자 통일, `->` ↔ `→`, 계수 `1` 생략 허용.

### 4. 그리기 답안 (`kind:'drawing'`)

- Canvas + Pointer Events. 펜(굵기 3단계)·직선(작도용)·지우개·색 6종·실행취소.
- 교사가 **밑그림 이미지**를 배경으로 깔 수 있다(모눈종이·광학 도해·지도).
- 저장은 **스트로크 JSON + 렌더 PNG 둘 다** — JSON은 이어서 수정하려고, PNG는 교사가 바로 보려고.
- 화면 회전·리사이즈에 안 깨지도록 스트로크는 **정규화 좌표(0~1)**로 저장한다.

### 5. 사진 업로드 답안 (`kind:'photo'`)

- `capture="environment"`로 모바일에서 카메라가 바로 열린다.
- 클라이언트에서 최대 1600px·JPEG 0.82로 리사이즈 → Drive 저장 → URL 반환.
  (원본 10MB까지, 리사이즈 후 2MB 초과면 거부)

### 6. 데이터표 자동계산·추세선 (`kind:'dataTable'`)

- 열 유형: 측정값 열(학생 입력) / 계산 열(교사가 수식 지정).
- 계산 수식은 **직접 만든 안전한 미니 파서**로 평가한다. **`eval`·`Function` 금지.**
  지원: `+ - * / ^ ( )`, 열 참조, `avg sum min max count stdev abs sqrt log ln`.
- 차트: 산점도/꺾은선/막대 + **선형 회귀 추세선**(기울기·절편·R²) + 오차막대. 입력 즉시 다시 그린다.
- ⚠️ 원안의 `answerTargets`(기울기·절편 자동 채점)는 **2026-07-29에 제거**됐다 —
  그리기·사진과 같은 "교사 수기 확인" 패턴으로 통일.

### 7. 참고자료 패널

- 우하단 플로팅 버튼 → 드로어(모바일은 바텀시트). 슬라이드를 벗어나지 않는다.
- 탭: **주기율표**(118종 한국어 명칭 정적 JSON 번들) · **과학 상수표** · **단위 환산기**
  (2번의 레지스트리 재사용) · **교사 커스텀 자료**. 교사가 수업별로 표시 여부와 탭을 고른다.

### 8. 학급 응답 집계 공유

- `getAggregate(code, questionId)`는 **집계만** 반환한다 — 이름·학번 절대 미포함.
- `shareClassResponses`가 켜진 문항이면 제출 후 분포가 나타난다(선택형=막대, 수치형=히스토그램,
  서답형=짧은 답안 익명 목록).
- 폴링은 **그 문항이 화면에 보일 때만**(IntersectionObserver), 벗어나면 즉시 중단 + 서버 캐시.

### 9. 예측-관찰-설명(POE) 잠금

- `poeGroup` 블록이 예측 문항 1개 + 관찰 블록 + 설명 문항 1개를 묶는다(**렌더링은 안 한다**).
- 예측을 제출하면 **잠긴다**. **서버도 재수정을 거부한다**(개발자도구 우회 방지).
- 마지막 요약에서 **내 예측 vs 내 설명**을 나란히 보여줘 개념 변화를 스스로 확인하게 한다.

### 10. 조건 분기 + 4-1 / 4-2 슬라이드 번호

- **"보조 슬라이드"**로 지정하면 직전 메인의 하위가 되어 `4-1`·`4-2`로 자동 번호
  (`lib/numbering.ts`가 매번 재계산 — **번호를 데이터에 저장하지 않는다**).
- 분기 규칙: "1번이 틀리면 → 4-1(보충), 맞으면 → 5". 보기별 분기도 가능.
- 진행 바는 **메인 슬라이드 기준**이라 보조로 빠져도 진행률이 요동치지 않는다.
- 분기로 건너뛴 슬라이드의 문항은 미응답 검사에서 제외(`lib/validate.ts`).
- 에디터가 **순환 분기**와 **도달 불가 슬라이드**를 검사해 경고한다.

## 교사 미리보기 / 테스트 모드 (2단계로 분리)

**① 미리보기 — 에디터 내 토글**: 현재 슬라이드를 학생 화면 그대로 렌더. 저장·제출·채점 없음.
**모바일(390×844) / 데스크톱** 프레임 전환. 플레이어 컴포넌트를 읽기 전용으로 재사용한다.

**② 테스트 모드 — `/#/play/:code?test=<editToken>`**: 학생과 **완전히 동일한 흐름**. 다만
`테스트 모드` 배너 + `처음부터 다시` · 응답은 `_test` 시트로 가서 통계·엑셀에서 **제외** ·
`정답 보기` 토글 · `잠금 무시하고 넘기기` · 통과한 **분기 경로** 표시.
⚠️ 이 링크는 `editToken`을 담고 있어 **학생에게 주면 안 된다**(경고를 함께 노출).

## 화면 설계

- **홈** — 학생용 코드 입력 / 교사용 "새 수업"·"수업 파일(.json) 가져오기"·**"QR코드 생성하기"**
  (QR·직접입장 링크 생성이 에디터 안에 묻혀 있어 홈으로 전면 배치, 2026-07-29). 맨 아래 관리자 링크.
- **교사 에디터** — 좌 슬라이드 목록 / 중앙 캔버스. 블록 추가는 hover `+`와 하단 버튼
  (슬래시 커맨드는 안 만들었다 → `DECISIONS.md`). 재정렬 `@dnd-kit`.
  리치텍스트는 **TipTap**(contentEditable을 직접 구현하지 않는다) + Subscript/Superscript + `mathInline`.
  이미지는 드래그앤드롭 → 클라이언트 리사이즈 → 업로드. 영상은 URL로 YouTube/Vimeo/mp4 자동 판별 +
  구간 재생. **자동저장 + 상단 저장 상태 표시**, `발행`으로 학생 접속 활성화.
- **학생 플레이어** — 한 화면 = 한 슬라이드. 상단 진행 바 + `4-1 / 12`, 하단 고정 `이전/다음`.
  **진행 잠금**: 필수 미응답이 있으면 `다음` 비활성 + 첫 미응답으로 스크롤 + 붉은 테두리 + 토스트.
  **피드백**은 `feedbackMode`에 따라 즉시 / 마지막에 일괄 / 미공개.
  **자동저장·복구**: 입력 즉시 localStorage, 디바운스로 서버 동기화 —
  새로고침·네트워크 끊김·**기기 변경** 시 같은 식별정보로 이어서 진행.
- **교사 결과** — 요약 카드 / 문항별 정답률·분포 / 학생별 답안 표(모바일은 카드) /
  사진·그림 썸네일 격자 / 서답형 모아보기 / **SheetJS로 `.xlsx` 클라이언트 생성** / 데이터 완전 삭제.

## 제품 자체의 유지보수성 ★

사이트를 계속 고치면 **이미 만들어 둔 수업 데이터가 깨질 수 있다.** 처음부터 방어한다.

- **스키마 버전 + 마이그레이션** — `Lesson.version`을 바꾸는 변경은 `lib/migrate.ts`에 변환 함수를
  누적하고 불러올 때 항상 통과시킨다. **옛 수업이 안 열리는 상황을 만들지 않는다.**
  마이그레이션마다 Vitest 픽스처를 붙인다.
- **수업 내보내기 / 가져오기 / 복제** — 백엔드 사고에 대한 최후의 백업이자, 교사끼리 공유하고
  다음 학년도에 재사용하는 수단. 제품 기능이자 유지보수 안전장치다.
- **`blocks/registry.ts` 패턴 유지** — 기능 추가가 파일 하나로 끝나는 구조를 지킨다.
  `switch`를 여기저기 늘리기 시작하면 유지보수가 무너진다.
- **순수 함수 + 단위 테스트** — 채점·단위·유효숫자·분기·번호 계산을 UI에서 분리해 테스트로 고정한다.
  **나중에 수정할 때 회귀를 막아주는 유일한 안전망이다.**
