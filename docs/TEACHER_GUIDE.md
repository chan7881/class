# 교사 사용 설명서

> 이 문서는 실제로 수업을 만들고 학생과 함께 쓰는 교사를 위한 사용법이다. 개발·설계 배경이 궁금하면 `docs/PLAN.md`를, 지금 개발이 어디까지 됐는지는 `docs/PROGRESS.md`를 보라.

## 1. 시작하기

1. 홈 화면에서 **"새 수업 만들기"**를 누르면 바로 편집 화면으로 이동한다.
2. 이 브라우저에 **편집 키**가 자동으로 저장된다 — 다른 기기나 브라우저에서 이어서 편집하려면 편집 화면 위쪽의 **"편집 키 보기"**로 복구 링크를 확인해 복사해 두어야 한다. **편집 키를 잃어버리면 그 수업을 다시 편집할 방법이 없다.**
3. 이미 만든 수업이 있으면 홈 화면에 **수업 코드**(6자리)를 입력해 참여하거나, 복구 링크로 편집 화면에 다시 들어갈 수 있다.

## 2. 슬라이드와 블록으로 학습지 만들기

- 왼쪽 목록에서 슬라이드를 추가·삭제·순서 변경할 수 있다.
- 슬라이드 안에서 **"+ 블록 추가"**(또는 블록에 마우스를 올렸을 때 나오는 **"＋"**)를 누르면 블록·문항을 고르는 메뉴가 뜬다.
- **콘텐츠 블록 8종**: 텍스트, 제목, 이미지, 영상(유튜브/비메오 URL + 구간 재생), 강조 상자, 구분선, 시뮬레이션 임베드(GeoGebra·PhET 등), 차트(교사가 입력한 데이터로 그래프).
- **문항 12종**: 빈칸채우기·선택형·서답형·합답형·순서배열·연결형(기본 6종) + 수치형·수식·화학식·데이터표·그리기·사진 업로드(과학 특화 6종). 문항마다 필수 여부·배점·해설을 정할 수 있다.
- 텍스트 안에서 글자를 드래그하면 굵게·기울임·색·크기 등을 바꾸는 도구 모음이 뜬다.

### 보조 슬라이드(4-1, 4-2 …)

슬라이드를 "보조 슬라이드"로 지정하면 바로 앞 메인 슬라이드의 하위로 붙어 "4-1", "4-2"처럼 번호가 자동으로 매겨진다. 보조 슬라이드는 **분기 규칙으로만** 도달하게 설계돼 있다 — 평범하게 "다음"을 누르면 건너뛴다.

### 조건 분기

문항이 있는 슬라이드 하단에서 분기 규칙을 정할 수 있다: "이 문항을 맞히면 5번으로, 틀리면 4-1(보충)로" 같은 규칙, 또는 특정 보기를 선택했을 때의 분기도 가능하다. 도달할 수 없는 슬라이드나 빠져나올 수 없는 순환 분기가 있으면 편집 화면 위쪽에 경고가 뜬다.

## 3. 과학 특화 문항 다루기

- **수치형**: 정답·허용오차(절대값 또는 %)·단위·유효숫자를 설정할 수 있다. 학생은 숫자와 단위를 따로 입력한다.
- **수식**: 학생은 키보드가 아니라 버튼(분수·루트·그리스 문자·단위·화학 기호 등)으로만 입력한다 — LaTeX 문법을 몰라도 된다.
- **화학식**: 아래첨자·위첨자·화살표·전하 등을 버튼으로 넣는다. `H2O`를 `H₂O`로 자동 변환하지 않는다 — 학생이 직접 첨자 버튼을 눌러야 한다.
- **데이터표**: 학생이 입력하는 측정값 열과, 교사가 수식(예: `A / B`, `avg(A)`)으로 지정하는 계산 열을 함께 만들 수 있다. 산점도·꺾은선·막대 그래프와 추세선(회귀직선)을 자동으로 그려주고, 추세선의 기울기·절편 자체를 허용오차 안에서 채점할 수도 있다.
- **그리기 / 사진 업로드**: 정답 개념이 없어 자동 채점되지 않는다(제출은 되지만 점수 합계에서 제외됨) — 교사가 결과 화면에서 직접 확인한다. **이 두 유형을 추가하면 편집 화면에 "학생 사진·그림은 운영 계정 Drive에 저장된다"는 경고가 뜬다** — 학생에게 얼굴이나 개인정보가 찍히지 않도록 미리 안내할 것.

## 4. 예측-관찰-설명(POE)

1. 예측 문항(서답형 등)에서 **"제출 후 잠금(POE 예측용)"**을 켠다.
2. 슬래시 메뉴에서 **"POE 묶음"** 블록을 추가하고, 예측 문항과 설명 문항을 골라 짝지어 둔다.
3. 학생이 예측 문항에 답을 쓰면 **"예측 제출하기"** 버튼이 나타나고, 누르면 그 답은 다시 고칠 수 없게 잠긴다(서버도 재수정을 거부한다).
4. 제출 화면에서 학생은 자신의 "예측 vs 설명"을 나란히 보고 스스로 개념 변화를 확인한다.

## 5. 학급 응답 분포 공유

문항 편집기에서 **"학급 응답 분포 공유"**를 켜면, 학생이 그 문항에 답한 뒤 화면 아래에 반 전체의 답 분포(막대그래프)가 자동으로 나타난다. 이름·학번은 절대 보이지 않고 집계된 숫자만 보인다.

## 6. 참고자료 패널

설정(⚙️)에서 "참고자료 패널"을 켜고 원하는 탭(주기율표·과학 상수표·단위환산기·직접 쓰는 자료)을 고르면, 학생 화면 오른쪽 아래에 버튼이 생겨 슬라이드를 벗어나지 않고도 언제든 열어볼 수 있다.

## 7. 미리보기 vs 테스트 모드

두 가지 확인 방법이 있다 — 용도가 다르다.

| | 미리보기 | 테스트 모드 |
|---|---|---|
| 여는 방법 | 편집 화면의 "미리보기" 버튼 | 편집 화면의 "테스트 모드" 버튼(새 창) |
| 저장 여부 | 저장·채점 기록 전혀 안 남음 | 실제로 서버에 저장되지만 **`_test`로 분리**돼 통계·엑셀에서 제외됨 |
| 용도 | 지금 편집 중인 화면이 학생 눈에 어떻게 보이는지 빠르게 확인 | 발행 전(또는 발행 후) **학생과 완전히 같은 흐름**으로 끝까지 눌러보며 분기·잠금·필수 문항이 의도대로 동작하는지 확인 |
| 전용 도구 | 모바일/데스크톱 화면 전환 | 정답 보기 토글, 잠금 무시하고 다음(필수 미응답이어도 통과), 처음부터 다시, 지나온 분기 경로 표시 |

**주의**: 테스트 모드 링크에는 편집 키가 그대로 들어 있다. **학생에게 공유하면 안 된다.**

## 8. 발행과 학생 참여

편집 화면에서 **"발행"**을 누르면 학생이 수업 코드로 들어올 수 있게 된다. 발행 후 "편집 키 보기"를 열면 학생에게 나눠줄 **참여 링크**(또는 그냥 6자리 코드)를 복사할 수 있다. 발행 이후에도 계속 편집·재발행할 수 있다.

## 9. 결과 확인·엑셀·데이터 관리

편집 화면의 **"결과 보기"**로 이동하면:
- 접속·제출 인원, 평균 점수, 평균 소요 시간
- 문항별 정답률과 답 분포(막대그래프)
- 학생별 답안 표(정답은 초록, 오답은 빨강 배경)
- 학생이 올린 사진·그림 모아보기
- **".xlsx 내려받기"**로 엑셀 파일을 바로 받을 수 있다(학생별 행, 문항별 답/정오/점수 열)
- **"수업 데이터 완전 삭제"**를 누르면 그 수업의 응답·미디어가 전부 지워진다 — **되돌릴 수 없다.**

## 10. 수업 내보내기 · 가져오기 · 복제

- 편집 화면의 **"내보내기(.json)"**로 지금 수업 전체(정답 포함)를 파일로 내려받을 수 있다 — 백업이나 다른 교사와 공유용.
- 홈 화면의 **"수업 파일(.json) 가져오기"**로 그 파일을 다시 올리면, 완전히 새로운 수업 코드·편집 키로 복사본이 만들어진다(원본은 그대로 있고, 항상 미발행 상태로 시작).
- 편집 화면의 **"복제"**는 지금 수업을 그 자리에서 바로 복사해(제목에 "(사본)" 붙음) 새 편집 화면으로 이동한다 — 같은 학습지를 다른 반에서 재사용할 때 편리하다.

## 11. 자주 있는 문제

- **편집 키를 잃어버렸다** → 복구할 방법이 없다. 발행 화면에서 미리 복사해 두는 습관이 중요하다.
- **학생이 "다음"을 눌러도 안 넘어간다** → 필수 문항에 답을 안 했을 확률이 높다. 빨간 테두리가 있는 문항을 확인하라.
- **정답을 다 알고 있는데도 채점이 "미채점"으로 나온다** → 그리기·사진 업로드는 원래 자동 채점이 안 된다(교사가 직접 확인).
- **테스트 모드에서 답을 잠갔는데 계속 나온다** → "처음부터 다시"를 누르면 새로 시작할 수 있다.
