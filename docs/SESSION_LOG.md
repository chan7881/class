- **검증 중 QR 오버레이의 실제 버그 1건 발견·수정**: 뷰포트가 낮은 창에서 QR 확대 오버레이의 "닫기" 버튼이 화면 아래로 잘려 클릭이 거의 불가능했다(콘텐츠가 넘치는데 스크롤 처리가 없었음) — `overflow-y-auto` + `min-h-full` 구조로 수정. 나머지 13건은 전부 의도한 대로 동작 확인, 사소한 부수 관찰 1건(리로드 후 서식 드롭다운 표시값 불일치, 실제 서식은 정상 적용됨 — 요청 밖이라 이번엔 미수정) 외엔 문제없음.
- 서브에이전트 병렬 실행 중 겪은 새로운 자동화 함정: 같은 Chrome 탭 그룹을 여러 세션이 동시에 쓰면 한 에이전트가 만든 탭이 다른 세션에 의해 URL이 바뀌거나 닫힐 수 있다(코드 문제 아님, 새 탭으로 재시작해 우회). `resize_window` 툴이 이 환경에서 실제로 뷰포트를 바꾸지 못해 모바일 폭 검증은 다음으로 미룸. 둘 다 `docs/PROGRESS.md` 미해결 이슈에 기록.
- `Code.gs`를 크게 손댔다(이미지 URL 패턴 교체, 관리자 API 3종 추가, 데이터표 채점 코드 ~250줄 삭제, 서답형 키워드 채점 추가) — **사용자가 script.google.com에서 재배포해야 반영된다.** 관리자 화면(`/#/admin`)도 쓰려면 스크립트 속성에 `ADMIN_PASSWORD`를 추가로 등록해야 한다. 둘 다 `apps-script/SETUP.md`에 절차 추가해둠. `npm install`(qrcode 패키지)은 이번 세션에 직접 실행 완료.
- `qrcode`/`@types/qrcode` 패키지 신규 설치, `xlsx`의 `XLSX.read`를 처음 사용(차트 엑셀 업로드용) — 기존 "XLSX.read는 어디서도 안 쓴다" 결정에 대한 의도적 예외, 근거는 `docs/DECISIONS.md`.
- **다음 세션이 알아야 할 것**: 남은 "사용자가 해야 할 일"은 Code.gs 재배포 + ADMIN_PASSWORD 등록 2가지뿐이다(둘 다 안 하면 이미지·관리자 화면·서답형 키워드 채점·데이터표 무채점이 **실사이트(live)**에는 아직 반영 안 된 상태). 브라우저 검증은 mock 모드 기준으로는 이미 다 끝났으니, 재배포 후엔 실사이트에서 6번(이미지)·2번(관리자)만 한 번 더 확인하면 된다.
